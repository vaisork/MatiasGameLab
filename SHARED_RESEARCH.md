# Investigación compartida entre proyectos

Este documento funciona como punto de recepción para hallazgos reutilizables provenientes de investigadores de otros proyectos de Javier, inicialmente Canvas 90 Works.

## Principio

Los investigadores pueden aprender unos de otros aunque trabajen en proyectos, chats, proveedores de IA o herramientas diferentes. GitHub conserva la transferencia.

Una transferencia debe separar:
- hallazgo generalizable;
- evidencia o razonamiento que lo sostiene;
- contexto donde fue observado;
- límites y condiciones;
- proyecto de origen;
- posible aplicación aquí.

**Una transferencia no es una orden ni una decisión automática.** El Arquitecto y los responsables de Vintage Telnet conservan su autoridad. El investigador receptor puede validar, ampliar, refutar o adaptar el hallazgo antes de usarlo.

## Regla contra contaminación

No importar mecánicas, canon, decisiones creativas, arquitectura específica ni procesos particulares de otro proyecto como si fueran válidos aquí. Solo se comparte conocimiento cuando existe una razón clara para que sea reutilizable.
