# MatiasGameLab

Dos proyectos independientes:

- **Vintage Telnet 2**, base actual: [entrada técnica](vintage-telnet-2/README.md), [agentes](vintage-telnet-2/AGENTS.md), [juego oficial](https://raspberrypi.tail3d212e.ts.net/).

[Vintage Telnet 1](vintage-telnet/AGENTS.md) se conserva como legacy/rollback. No recibe tareas nuevas.

Antes de trabajar lee [AGENTS.md](AGENTS.md) y [REPO_STRUCTURE.md](REPO_STRUCTURE.md). [MIGRATION_REPORT.md](MIGRATION_REPORT.md) registra movimientos, validación, límites y reversión. Documentación compartida en `docs/shared/`; historia en `docs/archive/` y archivos de cada proyecto.

El portal web conserva accesos anteriores. Runtime, partidas y secretos no forman parte del repositorio.
