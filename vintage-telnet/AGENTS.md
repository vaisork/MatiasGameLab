# Vintage Telnet 1 — legacy y rollback

Esta implementación fue sustituida por VT2. No asignar tareas nuevas ni ejecutar colas antiguas aquí. Mantener código, tests, canon y datos recuperables; no importar este motor a VT2.

Cualquier reparación de rollback o ejecución de herramientas debe tener autorización específica. El pipeline `tools/vt_art`, `scripts/validate-vintage-content.py`, `assets/vintage-telnet`, `art-masters` y launchers históricos conserva rutas por compatibilidad; no genera/publica arte para VT2 automáticamente.

Los documentos de raíz trasladados viven en `docs/archive/`. No tratarlos como requisitos actuales. Para trabajo nuevo entrar en `../vintage-telnet-2/AGENTS.md`. No desplegar a Raspberry ni restaurar datos por iniciativa propia.
