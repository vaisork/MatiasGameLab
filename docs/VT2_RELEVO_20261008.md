## Cómo actualizar la instalación Raspberry

Cada actualización del servidor requiere autorización para esa ejecución. No basta con que exista un nuevo commit en main. El procedimiento utilizado fue:

1. Preparar una entrega de un SHA concreto de Git, con manifiesto SHA256 de archivos públicos; transferirla por SSH/SCP a una carpeta de staging distinta de la instalación activa.
2. Verificar archivos y ejecutar pruebas aisladas en Raspberry con su `.venv`; no usar partidas reales como fixtures.
3. Respaldar código y configuración privada con permisos privados; detener el servicio antes de obtener una copia SQLite consistente, comprobar integridad.
4. Copiar el código de staging preservando `runtime/`, `.venv/` y archivos privados. No sustituir la base con una copia de Ubuntu, ni usar sincronización destructiva sobre la carpeta activa.
5. Arrancar el servicio, comprobar localhost y HTTPS, verificar versión, integridad y conservación de cuentas/personajes/progreso. Escribir `runtime/deployed-version.txt` sólo tras comprobar el arranque.

Comandos de servicio durante una ejecución autorizada:

```bash
systemctl --user stop vintage-telnet-nuevo.service
# Respaldo consistente y copia verificada del código preparado.
systemctl --user start vintage-telnet-nuevo.service
systemctl --user is-active vintage-telnet-nuevo.service
journalctl --user -u vintage-telnet-nuevo.service -n 80 --no-pager
```

## Cómo se trabajó y qué debe conservarse

Se localizaron primero canon, entregas y código vigente; las entregas se reconciliaron por IDs, sin reemplazar carpetas completas. Servidor y SQLite son autoridad; HTML y 3D muestran la misma geografía descubierta. Cada cambio lleva pruebas focales y evidencia que distingue fixtures de producción.

El mapa usa un atlas estable para 183 salas y seis reservas de hogares, 202 caminos. Los cinco ciclos espaciales suman 1002 movimientos de prueba: 190 caminos públicos rectos, seis curvas reales explicadas y seis enlaces de hogares. No se cambiaron salidas para arreglar el dibujo. Quedan dos cruces rurales esquemáticos representados con discontinuidad gráfica; no indican conexión. Ningún cruce de calles en pueblos. No interpretar coordenadas esquemáticas como distancias físicas exactas.

La redacción debe mantener pistas y relaciones espaciales, separar descripción permanente de hora/clima/NPCs y evitar repetirlo todo al regresar. `mirar` ofrece detalle; la navegación habitual debe conservar ritmo. Diálogo claro para niños, causas visibles y consecuencias reales, sin prosa ornamental ni cambios ficticios de estado.
